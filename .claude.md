# Gradient-Based Swarm Optimization via Softmin Energy Interactions

## Project Overview

PhD research on non-convex optimization in high dimensions using gradient-based swarm methods. The project introduces a Softmin Energy interaction $J_\beta(\mathbf{x})$ that couples particles through their relative energies, achieving provably faster transitions between local minima compared to overdamped Langevin dynamics.

**Paper Title:** 
*Accelerated Escape from Local Minima via Gradient-Informed Swarm Dynamics with Softmin Energy Coupling*

**Key Research Focus:**
- Gradient flow dynamics with Softmin Energy interaction
- Noisy dynamics and stochastic differential equation (SDE) analysis
- Eyring-Kramers-type estimates for effective potential barriers
- Convergence acceleration vs. Langevin dynamics
- Numerical validation on benchmark problems

### Core Notation

**Vectors and Matrices:**
- Particles: $\mathbf{x}_i$ or $\mathbf{x}^{(i)}$ (bold for vectors)
- Position of particle $i$: $\mathbf{x}_i \in \mathbb{R}^d$
- Objective function: $f: \mathbb{R}^d \to \mathbb{R}$

**Energy and Dynamics:**
- Softmin Energy (per particle): $J_\beta(\mathbf{x}_i) = -\frac{1}{\beta} \log \left( \frac{1}{n} \sum_{j=1}^{n} e^{-\beta f(\mathbf{x}_j)} \right)$
- Gradient: $\nabla J_\beta(\mathbf{x}_i)$ (always with $\nabla$, never $\partial$)
- Step size / learning rate: $\alpha$ or $\gamma$
- Noise level: $\sigma$ (standard deviation)
- Annealing parameter: $\beta(t)$ (inverse temperature, increasing over time)

**Stochastic Differential Equation (SDE):**
```latex
d\mathbf{x}_i(t) = -\nabla J_\beta(\mathbf{x}_i(t)) \, dt + \sigma \, dW_i(t)
```
where $W_i(t)$ is standard Brownian motion.

**Brownian Motion:**
- Standard notation: $W_i(t)$ or $\mathbf{W}_i(t)$ (use \mathbf for vector BM)
- Increments: $dW_i \sim \mathcal{N}(0, dt)$

## Softmin Energy and Core Algorithm

### Energy Function Definition

The Softmin Energy is the central object in this work:

$$J_\beta(\mathbf{x}_i) = -\frac{1}{\beta} \log \left( \frac{1}{n} \sum_{j=1}^{n} e^{-\beta f(\mathbf{x}_j)} \right)$$

**Key Properties:**
- Couples all particles through their objective values
- As β → ∞, becomes pointwise minimum of particles' objectives
- Gradient ∇J_β provides coupled, energy-aware update direction
- Smooth approximation avoids non-differentiability of min operator

### Gradient Computation

The key challenge: computing ∇J_β(x_i) efficiently and numerically stably.

**Analytical form:**
$$\nabla J_\beta(\mathbf{x}_i) = \sum_{j=1}^{n} w_j(\mathbf{x}) \cdot \nabla f(\mathbf{x}_j)$$

where $w_j(\mathbf{x}) = \frac{e^{-\beta f(\mathbf{x}_j)}}{\sum_k e^{-\beta f(\mathbf{x}_k)}}$ is a softmax weight.

**Numerical stability consideration:**
- Compute in log-domain: log w_j = -β f(x_j) - logsumexp(...)
- Use scipy.special.logsumexp for numerical safety
- Never compute exp(-β f) directly when β is large

**Code requirement:**
```python
def softmin_gradient(positions, objectives, beta, objective_grad_fn):
    """Compute ∇J_β using log-domain arithmetic."""
    # Use logsumexp for stability
    log_weights = -beta * objectives - logsumexp(-beta * objectives)
    weights = np.exp(log_weights)  # Now safe after log-domain
    
    # Gradient: Σ w_j ∇f(x_j)
    gradients_f = objective_grad_fn(positions)  # (n, d)
    grad_energy = weights[:, None] * gradients_f  # Broadcasting
    return grad_energy.sum(axis=0)  # Sum over particles
```

### Annealing Schedule

The algorithm requires annealing β(t) → ∞ over time:

**Standard choices:**
- Linear: β(t) = β_0 + γ * t
- Exponential: β(t) = β_0 * exp(λ * t)
- Power: β(t) = β_0 + γ * t^p for p ∈ (0, 1]

**Constraint from theory:** 
β must increase fast enough for convergence guarantees, but not so fast that particles can't explore.

**Implementation:**
```python
def beta_schedule(t, beta_0, gamma):
    """Linear annealing: β(t) = β_0 + γ * t"""
    return beta_0 + gamma * t
```

### Gradient Flow (Deterministic Case, σ = 0)

**Equation:**
$$\frac{d\mathbf{x}_i(t)}{dt} = -\nabla J_\beta(\mathbf{x}_i(t))$$

**Analysis in Section 2:**
- Convergence to stationary points of J_β
- For λ-strongly convex f: at least one particle reaches global minimum
- Off-minimum particles exhibit exploratory behavior (don't all collapse)

**Code implication:**
```python
def gradient_flow_step(positions, objectives, beta, objective_grad_fn, dt):
    """Deterministic step (σ=0)."""
    grad_energy = softmin_gradient(positions, objectives, beta, objective_grad_fn)
    positions_new = positions - grad_energy * dt
    return positions_new
```

### Noisy Dynamics (Full SDE)

**Equation:**
$$d\mathbf{x}_i(t) = -\nabla J_\beta(\mathbf{x}_i(t)) \, dt + \sigma \, dW_i(t)$$

**Analysis in Section 3:**
- Eyring-Kramers estimate: effective potential barriers < Langevin barriers
- Faster transitions between local minima
- Convergence acceleration is *interaction-driven* (from Softmin coupling)

**Euler Discretization:**
```python
def sde_euler_step(positions, objectives, beta, objective_grad_fn, dt, sigma):
    """Single Euler step of SDE."""
    grad_energy = softmin_gradient(positions, objectives, beta, objective_grad_fn)
    
    # Drift term: -∇J_β dt
    drift = -grad_energy * dt
    
    # Diffusion term: σ √dt N(0,1)
    n, d = positions.shape
    dW = np.random.randn(n, d) * np.sqrt(dt)
    diffusion = sigma * dW
    
    positions_new = positions + drift + diffusion
    return positions_new
```

### Solver Loop Structure

```python
def swarm_dynamics(objective_fn, objective_grad_fn, initial_positions,
                   beta_0, gamma, sigma, dt, num_steps):
    """Full algorithm: deterministic + annealing + noise."""
    positions = initial_positions.copy()
    trajectory = [positions.copy()]
    
    for t in range(num_steps):
        # 1. Update annealing parameter
        beta = beta_schedule(t, beta_0, gamma)
        
        # 2. Evaluate objectives
        objectives = objective_fn(positions)
        
        # 3. SDE step
        positions = sde_euler_step(positions, objectives, beta, 
                                    objective_grad_fn, dt, sigma)
        
        trajectory.append(positions.copy())
    
    return positions, trajectory
```

## Hitting Times and Barrier Crossing Analysis

### Theory (Section 3 in Paper)

The main theoretical result compares hitting times to the global minimum:

**Notation:**
- τ = hitting time (first time reaching global minimum)
- ΔU_eff = effective potential barrier (from Eyring-Kramers estimate)
- For Langevin: τ_Langevin ~ exp(ΔU_Langevin / T)
- For Softmin Swarm: τ_Swarm ~ exp(ΔU_eff / T), where ΔU_eff < ΔU_Langevin
